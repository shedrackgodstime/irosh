# Changelog

All notable changes to irosh are documented here.

## [Unreleased] - v0.5.0

Hardening and tooling: runtime metrics counters, tracing coverage across
the public API, CI fuzz targets with a coverage gate, transfer and SSH
benchmarks, and 17 public API soundness fixes.

## [0.4.0] - 2026-05-31

Windows stability (job objects, static CRT), installer polish, public-key
rate limiting, transfer resize forwarding, and storage/config test suites.

## [0.3.0] - 2026-05-15

Terminal state restoration, IPC shutdown sync, Windows ACL hardening,
structured transfer errors, and a broad polish pass.

## [0.2.0] - 2026-05-07

Unified single-binary CLI, wormhole rendezvous codes, a unified authenticator
with rate limiting, daemon-first IPC control, and cross-platform service
management.

## [0.1.0] - 2026-04-20

Initial release: SSH sessions over the Iroh P2P transport, TOFU trust, and
recursive file transfers.
